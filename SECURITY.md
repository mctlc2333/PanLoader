# 🔒 Security Policy

## Reporting a Vulnerability

We take the security of PanLoader seriously. If you discover a security vulnerability, please **do not** report it in a public GitHub Issue.

### How to Report

Please contact us privately:

- 📧 Email: [admin@creature.ro]
- 🔐 If needed, you may encrypt your message using our [PGP key].

### Reporting Process

1. We will acknowledge your report within 48 hours.
2. We will assess the impact and severity.
3. We will fix the issue and release a patch.
4. After the fix is published, we will disclose the vulnerability (coordinated with the reporter).

## Supported Versions

| Version | Supported |
|---------|-----------|
| Latest  | ✅ Yes    |
| Older   | ❌ No, please upgrade |

## Security Best Practices

- Always use the latest version of PanLoader.
- Only download from official sources (GitHub Releases).
- Do not run untrusted mods.
